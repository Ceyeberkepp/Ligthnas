# LightNAS Code of Conduct

## Our commitment

The LightNAS community is committed to providing a respectful, professional, and welcoming environment for everyone participating in the project, regardless of experience level, background, identity, location, role, or technical specialty.

This Code of Conduct applies to project repositories, issues, pull requests, discussions, reviews, documentation, community spaces, and other official LightNAS collaboration channels.

## Expected behavior

Participants are expected to:

- Treat other contributors and users with respect and patience.
- Give technical feedback about code, design, documentation, or behavior without attacking the person who created it.
- Assume good intent while still raising security, quality, licensing, and safety concerns clearly.
- Keep discussions relevant to LightNAS and its development.
- Provide enough technical detail for others to reproduce and understand reported problems.
- Respect maintainers' decisions about project scope, architecture, release readiness, licensing, and security.
- Protect private information, credentials, security findings, customer data, and other sensitive material.
- Credit the work of others when reusing ideas, patches, research, or documentation.
- Follow the LightNAS license and applicable third-party licenses.

## Unacceptable behavior

The following behavior is not acceptable:

- Harassment, threats, intimidation, stalking, or sustained personal attacks.
- Discrimination or derogatory comments directed at an individual or group.
- Sexual harassment or unwanted sexual attention.
- Publishing another person's private information without permission.
- Deliberately exposing passwords, API keys, tokens, private keys, personal data, or confidential infrastructure details.
- Publishing unpatched LightNAS security vulnerabilities when a private reporting path is available.
- Spam, repeated disruptive promotion, or intentionally derailing technical discussions.
- Knowingly submitting malicious code, backdoors, credential stealers, destructive payloads, or misleading security changes.
- Misrepresenting authorship, test results, compatibility, release status, or licensing.
- Pressuring contributors or maintainers to approve unsafe, untested, or out-of-scope changes.
- Using project spaces to facilitate unlawful activity.

## Technical disagreement

Strong technical disagreement is allowed. LightNAS includes storage, networking, authentication, containers, virtual machines, host-level services, and other infrastructure components where mistakes can have serious consequences.

Disagreement should focus on evidence such as:

- reproducible behavior;
- logs and diagnostics;
- code and architecture;
- tests and benchmarks;
- security impact;
- compatibility impact; and
- documented product requirements.

Maintainers may reject a proposal without rejecting the contributor.

## Security-sensitive discussions

Do not post working exploit details, secrets, credentials, private infrastructure information, or unpatched vulnerability details in public issues, pull requests, or discussions.

Follow [SECURITY.md](SECURITY.md) for vulnerability reporting.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on severity and history, maintainers may:

1. provide a private or public warning;
2. edit, hide, lock, or remove disruptive content where the platform allows;
3. close or reject an issue or pull request;
4. temporarily restrict participation;
5. permanently block participation in official LightNAS project spaces; or
6. escalate credible threats, abuse, or unlawful behavior to the relevant platform or authorities.

Maintainers should apply enforcement in good faith and as consistently as reasonably possible.

## Reporting a conduct problem

For ordinary project disagreements, use the relevant issue, pull request, or discussion and keep the conversation technical.

For harassment, threats, privacy concerns, or another conduct matter that should not be public, contact the LightNAS repository owner or maintainers through an available private GitHub contact method. Do not include sensitive personal information in a public issue.

Security vulnerabilities must be reported according to [SECURITY.md](SECURITY.md).

## Scope

This Code of Conduct governs participation in official LightNAS project spaces. It does not change the LightNAS software license, create employment or support obligations, or grant rights beyond those stated in the repository's [LICENSE](LICENSE).

By participating in the LightNAS project, you agree to follow this Code of Conduct.
